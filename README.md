# CULT Clinic

Приложение для iPhone лежит в папке `mobile` и написано на Flutter. Это отдельная программа с иконкой CULT, не вкладка браузера. Собрать её на iPhone можно только на Mac с Xcode: Apple не подписывает приложения с Linux.

```bash
cd mobile
flutter pub get
flutter run
```

Телефон подключается кабелем, на нём нужно доверить компьютер. Либо откройте `mobile/ios/Runner.xcworkspace` в Xcode и нажмите Run. Репозиторий: https://github.com/sifonyarya-afk/cult

Запись в реальный филиал подключается в кабинете, пункт «YClients»: ID компании и партнёрский токен из маркетплейса. Без них визиты остаются на телефоне.

Веб-версия для браузера остаётся в корне проекта.

Мобильное веб-приложение косметологической клиники CULT: приветственный экран, бонус, кабинет, услуги, аппаратная и инъекционная косметология, инфузии, наука, магазин и чат.

Интерфейс повторяет телефонные макеты: узкая колонка по центру экрана, тёплая клиническая палитра, русские тексты. Данные локальные, без сервера и базы.

## Запуск

```bash
npm install
npm run dev
```

Сервер разработки слушает `0.0.0.0:38471`.

Откройте [http://127.0.0.1:38471](http://127.0.0.1:38471).

Сборка:

```bash
npm run build
npm start
```

| `/devices/[slug]` | Карточка аппарата |

| `/shop/[id]` | Карточка товара |
