# CULT Clinic

Мобильное веб-приложение косметологической клиники CULT: приветственный экран, бонус, кабинет, услуги, аппаратная и инъекционная косметология, инфузии, наука, магазин и чат.

Интерфейс повторяет телефонные макеты: узкая колонка по центру экрана, тёплая клиническая палитра, русские тексты. Данные локальные, без сервера и базы.

## Запуск

```bash
npm install
npm run dev
```

Сервер разработки слушает `0.0.0.0:38471`.

Откройте [http://127.0.0.1:38471](http://127.0.0.1:38471).

Сборка:

```bash
npm run build
npm start
```

## Маршруты

| Путь | Экран |
| --- | --- |
| `/` | Видео-заставка, около 2,6 с, затем переход |
| `/welcome` | Бонус для новых клиентов |
| `/home` | Главная |
| `/cabinet` | Личный кабинет |
| `/cabinet/visits` | Визиты |
| `/services` | Каталог услуг |
| `/services/[slug]` | Карточка услуги |
| `/specialists` | AlethiaPro |
| `/doctors/thorne` | Д-р Элара Торн |
| `/hardware` | Аппаратная косметология |
| `/devices/[slug]` | Карточка аппарата |
| `/injection` | Инъекционная косметология |
| `/infusion` | Инфузии |
| `/science` | Наука |
| `/shop` | Биохакинг-шоп |
| `/chat` | Чат с клиникой |
| `/chat/[id]` | Переписка, в том числе с врачом |
| `/doctors` | Врачи |
| `/doctors/julian` | Д-р Джулиан Торн |
| `/shop/[id]` | Карточка товара |
| `/cart` | Корзина и оформление |
| `/prices` | Прайс |
| `/blog`, `/blog/[slug]` | Блог и материал: читать или смотреть |
| `/tv` | Переход на YouTube |
| `/about` | О клинике |
| `/cases`, `/cases/[slug]` | Кейсы |
| `/booking` | Запись на услугу |
| `/transfer` | Заказ трансфера |
| `/pharmacy` | Личная аптека |
| `/loyalty` | Система лояльности |

Корзина, имя в кабинете и сообщения чата хранятся в `localStorage`.
