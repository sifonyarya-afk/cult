# CULT Clinic

Приложение клиники для iPhone. Запись, услуги, магазин, корзина, кабинет, чат и бонусы хранятся на телефоне.

Нужны Mac, Xcode и Flutter.

```bash
flutter pub get
flutter run
```

Подключите iPhone кабелем и подтвердите доверие к компьютеру. Сборку из Xcode открывайте так:

```bash
flutter pub get
cd ios
pod install
open Runner.xcworkspace
```

Нужен файл `Runner.xcworkspace`, не `Runner.xcodeproj`. Иначе Xcode пишет `Framework 'Pods_Runner' not found`.

В Xcode: цель Runner → Signing & Capabilities → Team. Выберите свой Apple ID (Personal Team). Без команды подписи сборка на iPhone не запускается. Если CocoaPods не установлен: `brew install cocoapods`.

Собрать установочный файл iPhone с Linux нельзя: подпись делает только Xcode.

## YClients

В кабинете откройте «YClients». Нужны ID филиала и партнёрский токен: его выдают после регистрации интеграции в маркетплейсе YClients, раздел «Настройки аккаунта», API-ключ. Токен хранится только на телефоне и в git не попадает.

Филиал CULT в Сочи (988587) уже указан в приложении. Прайс берёт услуги филиала из YClients. Свободные окна для онлайн-записи появляются, когда в филиале открыто расписание. Отмена такой записи тоже уходит в YClients. Карта лояльности читается по телефону клиента. Если филиал отключить в кабинете, визит снова сохраняется только на телефоне.
